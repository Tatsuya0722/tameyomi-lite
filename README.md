# ためよみ！ 軽量版

**[ゲームを開く](https://tatsuya0722.github.io/tameyomi-lite/) · [対人用の均衡手ガイド](https://tatsuya0722.github.io/tameyomi-lite/guide/)**

攻撃・防御・ためで気力を読み合う、資源付きじゃんけんです。ゲームは **4,294バイト**、ガイドは **4,697バイト**の単体HTMLで、外部ライブラリー・画像・通信・学習処理は使いません。

## ルール

- 双方の気力は0から開始し、上限はありません。
- 毎ターン同時に行動を選びます。攻撃は−2、防御は−1、ためは＋1。
- 気力不足の手は選べません。
- 攻撃とための組み合わせだけ、攻撃側が勝ちます。それ以外は気力を更新して続行します。

## 16bit確率の軽量CPU

- 高精度の均衡戦略を最大余剰法で量子化。各行動は0〜65535の整数で、3つの合計は65535です。
- 気力0〜9の範囲から必勝・必敗部分を除いた60局面を保存します。
- 攻撃・防御をそれぞれ16bitで保存。ためは `65535 − 攻撃 − 防御` で求めます。8bitずつの分解は行いません。
- 確率データ240バイトに行の位置情報を加え、表と読み出し関数は562バイトです。
- 範囲外では表の参照位置だけを9へ丸めます。実際の気力は制限しません。必勝領域では攻撃を続けます。
- 初期局面0対0からの最悪勝率は約49.998634％。整数演算による上下限は49.9986339127955407％〜49.9986339127955413％です。
- 暗号学的乱数で入力前に手を決定します。抽選値65535は引き直し、0〜65534の65535通りを均等に使います。

従来の合計255版は3,947バイト・最悪勝率約49.856300％でした。今回のゲーム容量増加は347バイト（約8.79％）、五分からの勝率低下は約105分の1です。任意の高い気力から開始した場合や、相手が未公開の抽選結果を事前に知る場合の保証ではありません。

画面の「CPU 22342」などは百分率ではなく、合計65535になる整数の重みです。一画面構成で、通常のスクロールとズーム操作を抑止しています。勝数はページを開いている間だけ保持します。

## 対人用の均衡手ガイド

同じCPUが抽選した次の一手を表示します。入力は同じ3つのボタンです。**表示された手を自分が出し、実際の対戦相手が出した手をボタンで入力**してください。気力を更新して次の手を表示します。画面は左が相手、右が自分です。

表示した手は入力まで固定します。決着後は「次のゲーム」で双方の気力を0に戻します。
