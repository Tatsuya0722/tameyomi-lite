# ためよみ！ 軽量版

**[ゲーム](https://tatsuya0722.github.io/tameyomi-lite/) · [対人用の均衡手ガイド](https://tatsuya0722.github.io/tameyomi-lite/guide/)**

気力を読み合う資源付きじゃんけんです。CPUは短い計算手順から起動時に表を生成し、初期0対0からの最悪勝率を倍精度の誤差程度まで50％に近づけています。UIは[1024版](https://github.com/Tatsuya0722/tameyomi-1024)の画面に合わせています。

## 容量と強さ

| 項目 | 結果 |
|---|---:|
| 戦略生成・参照コード | 1,125バイト |
| 独立CPUモジュール・乱数抽選込み | 1,300バイト |
| 配布する確率表 | 0バイト |
| ゲーム全体 | 9,873バイト |
| ガイド全体 | 9,927バイト |
| 初期0対0からの最悪勝率 | 約49.99999999999999％ |

50％からの低下は、確率で約1.127548092299307×10^-16です。今回の合格基準 `Number.EPSILON = 2^-52` 以下を満たします。絶対に誤差のない厳密均衡や、すべての可能なプログラムの中で最短であることを主張するものではありません。

計算・抽選を含む固定CPUに対し、BigIntによる下向き・上向きの丸めで次を確認しました。

```
0.49999999999999988724519077006930090
    ≤ 初期局面からの最悪勝率（確率） ≤
0.49999999999999988724519077006930094
```

保証は双方の気力0から始め、相手が確率表や過去の履歴を利用できる条件です。相手が未公開の抽選結果を事前に知る条件ではありません。任意の高い気力から開始した場合まで最悪勝率が50％になるという意味ではありません。

## ルールと操作

- 双方の気力は0から開始し、上限はありません。
- 攻撃は−2、防御は−1、ためは＋1。気力不足の手は選べません。
- 同時に手を出し、攻撃とための組み合わせだけ攻撃側の勝ち。それ以外は気力を更新して続行します。
- 決着後は「次のゲーム」で双方の気力を0に戻します。勝数はページを開いている間だけ保持します。

ガイドでは、表示された手を自分が出し、実際の相手が出した手を3つのボタンで入力してください。左が相手、右が自分です。表示した手は入力があるまで固定します。

## CPUの構成

気力0〜40の評価表を、起動時に256回の更新で生成します。各局面は最大3×3の行列ゲームとして解きます。準備にこの環境では約0.4〜1.3秒かかりました。端末で変動します。

その後は表を参照して手を選びます。気力が40を超えても実際の気力は制限せず、参照位置だけを丸めます。自分の気力が相手の2倍＋2以上の必勝領域では攻撃を続けます。

53bitの均等な暗号学的乱数を使い、入力前に手を確定します。画面の確率は1024版と同じ百分率で表示します。外部ライブラリー・外部データの取得・学習・画像ファイルは使いません。

## ファイル
