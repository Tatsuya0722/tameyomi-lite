# ためよみ！ 軽量版

**[ブラウザーで遊ぶ](https://tatsuya0722.github.io/tameyomi-lite/)**

攻撃・防御・ためで気力を読み合う、資源付きじゃんけんです。ゲーム本体は `index.html` の **3,947バイト**だけで、外部ライブラリー・画像・通信・学習処理は使いません。

## 対人用の均衡手ガイド

**[均衡手ガイドを開く](https://tatsuya0722.github.io/tameyomi-lite/guide/)**

軽量版CPUが抽選した次の一手を表示します。入力方法は同じ3つのボタンです。表示された手を自分が出し、実際の対戦相手が出した手をボタンで入力してください。気力を更新して、次の一手を表示します。画面では左が相手、右が自分です。

軽量版と同じ近似均衡表・抽選方式を使用し、表示した手は入力があるまで固定します。数字は自分の選択確率を表す0〜255の重みです。気力は双方0から開始し、決着後は「次のゲーム」でリセットできます。単体HTMLは4,346バイトです。

## ルール

- 双方の気力は0から開始し、上限はありません。
- 毎ターン同時に行動を選びます。攻撃は−2、防御は−1、ためは＋1。
- 気力不足の手は選べません。
- 攻撃とための組み合わせだけ、攻撃側が勝ちます。それ以外は気力を更新して続行します。

## 軽量CPU

- 高精度の均衡戦略を最大余剰法で量子化。各行動は0〜255の整数で、3つの合計は255です。
- 気力0〜5の36局面について、攻撃・防御の2つを保存。ためは残りから計算します。表の情報量は72バイト、表と読み出し関数のソースは220バイトです。
- 範囲外では表の参照先だけを端へ丸めます。実際の気力は制限しません。必勝領域では攻撃を続けます。
- 初期局面0対0からの最悪勝率は約49.8563％。整数演算による上下限は49.8563001057％〜49.8563001061％です。
- 暗号学的乱数でCPUの手をプレイヤー入力前に決定します。抽選値255は引き直し、0〜254の255通りを均等に使います。

画面の「CPU 87」などの数字は百分率ではなく、合計255になる整数の重みです。一画面構成で、通常のスクロールとズーム操作を抑止しています。勝数はページを開いている間だけ保持します。
